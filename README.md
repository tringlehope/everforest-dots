# Everforest M3 — Hyprland + Quickshell + SDDM

Минималистичное графическое окружение для Arch Linux в тёплой палитре **Everforest Dark (Soft)** без прозрачности и размытия, с элементами **Material You 3 Expressive** и иконками **Gruvbox-Plus-Dark**.

## Установка на чистый Arch Linux

    git clone <URL_ТВОЕГО_РЕПОЗИТОРИЯ> ~/everforest-dots
    cd ~/everforest-dots
    ./install.sh

## Основные горячие клавиши
- `Super` — единое меню приложений + док открытых окон
- `Super + Q` — терминал (`ghostty`)
- `Super + E` — файлы (`nautilus`)
- `Super + V` — переключить окно в плавающий режим
- `Super + C` — закрыть активное окно
- `Super + Колёсико` — переключение рабочих столов (1–9)
- `Super + 1..9` / `Super + Shift + 1..9` — переход / перенос окна на стол
